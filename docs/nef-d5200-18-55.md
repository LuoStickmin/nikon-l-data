# D5200 + AF-S DX 18-55 样片分析（2026-11-14）

四张 NEF，同场景、同焦距（55mm）、f/5.6，拍摄时间 21:19:55–21:20:13，机身 D5200。

## 1. 镜头识别（解密 MakerNote LensData）

NEF 的 LensData（MakerNote tag 0x0098）是加密的；用 ExifTool 文档里的算法（`Decrypt()` +
两张 256 字节 `xlat` 表，key 来自机身序列号和快门数）解出：

```
57AE18B5….NEF: 55mm f/5.6  lens 9A 40 2D 53 2C 3C 9C 3C (18-55mm f/3.6-5.7)  distort=1
7BCE423E….NEF: 55mm f/5.6  lens 9A 40 2D 53 2C 3C 9C 3C (18-55mm f/3.6-5.7)  distort=1
2EC435A0….NEF: 55mm f/5.6  lens 9A 40 2D 53 2C 3C 9C 3C (18-55mm f/3.6-5.7)  distort=0
F35FAD70….NEF: 55mm f/5.6  lens 9A 40 2D 53 2C 3C 9C 3C (18-55mm f/3.6-5.7)  distort=0
```

对照 ExifTool 的 LensID 表，前 7 字节 `9A 40 2D 53 2C 3C 9C` 对应 **AF-S DX VR Zoom-Nikkor
18-55mm f/3.5-5.6G**（表里的完整 ID 是 `9A 40 2D 53 2C 3C 9C 0E`；最后一位我们读成 0x3C，
应该是 LensType 的偏移/掩码问题，不影响前 7 字节的匹配）。

`distort=1/0` 来自 MakerNote tag 0x002B（DistortInfo）的第 5 字节，即 Auto distortion control
的开关：57AE、7BCE 为开，2EC4、F35F 为关。

## 2. 用 raw vs 机内 JPEG 测“相机实际施加的畸变校正”

思路：NEF 的 raw 是未校正的，机内 JPEG 是相机用 L 数据校正后的；同一张照片的 raw/JPEG 对比
可以消掉手持位移，直接量出校正映射。

做法（`tools/nef_measure_distortion.py`）：

1. rawpy 解 NEF raw（half_size，相机白平衡）→ 灰度；
2. 提取机内 JPEG（SubIFD0 的 0x0201/0x0202）→ 缩放到同尺寸；
3. SIFT + RANSAC 求对应点；
4. 拟合 `r_raw / r_jpeg = c0 + c1·r² + c2·r⁴ + c3·r⁶`（r 按半对角线归一化，中心可偏移）。

结果：

```
57AE (distort=On) : 0.990830 +0.001086 r² +0.002956 r⁴ -0.000371 r⁶   rmse 2.3e-4
2EC4 (distort=Off): 0.994815 -0.002145 r² +0.001699 r⁴ -0.000144 r⁶   rmse 2.8e-4
```

按 `r_raw = r_jpeg·(1 + k(ρ²)ρ² + k(ρ⁴)ρ⁴ + k(ρ⁶)ρ⁶)/(1+q)` 解读，On 片对应
`q≈0.0093, k2≈+0.0011, k4≈+0.0030, k6≈-0.0004`。

**但 Off 对照也给出了 ~0.2% 量级的形状项**，与 55mm 端本来就很小的畸变同量级——raw 与 JPEG
的渲染/缩放差异（去马赛克、锐化、裁切）会带来同量级的系统偏差。所以在 55mm 上这套测量还不足以
当作可信的“真值”，只能说明相机确实按开关施加了约 0.2–0.4% 量级的径向缩放。

## 3. 与 L 数据的对照

- 18-55 的 8 字节 LensID（`9A 40 2D 53 …`）**没有**出现在 NKLD0218/0217 里（全字节、前 4 字节、
  中段、逆序都搜过）；
- 说明 L 记录里的查找键不是直接存 LensID，或者记录头也被同一套按位置的密钥混淆了；
- 用我们解码出的 27 个值去拟合上面测到的系数，在允许逐列取反 + 缩放后有不少 3 维方向吻合的
  候选，但随机基线同样高（3 维、22k 个候选），**不能作为匹配依据**。

## 4. 结论与下一步

1. 镜头身份已确认：D5200 + AF-S DX VR 18-55 f/3.5-5.6G，55mm f/5.6。
2. 四张里两张开了失真控制、两张关了，可用于 A/B 对照。
3. 55mm 端畸变接近 0，且 raw/JPEG 系统偏差同量级，**这组样片不足以定标 L 数据**。
4. 真正有用的做法：用同一机身/镜头在 **18mm** 端拍带直线网格（瓷砖、窗框、标定板）的
   On/Off 两组，畸变 3–5%，信噪比高得多；到时候可以用同一套 `nef_measure_distortion.py`
   定出 k2/k4/k6，再和 L 数据里 18-55 的记录比对。

## 5. 工具

  内置 ExifTool 的两张 xlat 表，不依赖 exiftool。
- `tools/nef_measure_distortion.py`：raw vs 机内 JPEG 的径向校正测量。
