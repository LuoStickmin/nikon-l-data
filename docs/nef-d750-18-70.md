拍摄流程是 18mm 开、70mm 开、18mm 关、70mm 关，正好两组 On/Off 对照。

## 3. 18mm 端 raw vs 机内 JPEG 的畸变测量

方法和 D5200 那批相同（`tools/nef_measure_distortion.py`）：raw（未校正）与机内 JPEG
（相机用 L 数据校正）做 SIFT 匹配，拟合

`r_raw / r_jpeg = c0 + c1·r² + c2·r⁴ + c3·r⁶`（r 按半对角线归一化）。

18mm On（0586）：

```
ratio = 0.995713 +0.134747 r² -0.865158 r⁴ +1.151773 r⁶   rmse 1.9e-3  (2860 内点)
```

18mm Off 对照（0610）：

```
ratio = 0.991699 -0.011515 r² +0.030797 r⁴ -0.021228 r⁶   rmse 2.4e-3  (3578 内点)
```

分半径看：

| r | On 比值 | Off 比值 |
|---|---|---|
| 0.1–0.2 | 0.9977 | 0.9829 |
| 0.2–0.3 | 1.0024 | 0.9879 |
| 0.3–0.4 | 1.0022 | 0.9921 |
| 0.4–0.5 | 0.9968 | 0.9920 |
| 0.5–0.6 | 0.9928 | 0.9901 |
| 0.6–0.7 | 0.9855 | 0.9909 |

解读：

- On/Off 在 r≈0.2–0.4 处相差约 **+1.5%**，方向与“桶形校正把边缘拉直”一致；
- 但匹配点主要集中在 r<0.6（天空和地面缺少纹理），**角落（r>0.8）几乎没有对应点**，
  而 18mm 畸变的主要信号恰恰在角落；
- 因此这批数据只能说明“相机确实在 18mm 端施加了约 1–2% 量级的径向校正”，**还不足以
  拟合出可信的 k(ρ²)/k(ρ⁴)/k(ρ⁶)**，更不能拿去和 L 数据记录做定量比对。

## 4. 与 L 数据的关系

- D750 是支持 L 2.018 的机身，镜头 18-70 在 L 数据里应有对应记录；
- 但 L 记录的查找键仍未知（18-55 的 LensID 在 NKLD 里也搜不到），所以暂时无法把
  这批样片和具体记录对上；
- 这批样片的价值在于：**18mm 端有真实的、较大的畸变信号**，比 55mm 那批更适合定标。
  如果补拍时能对着带直线的目标（标定板、瓷砖墙、窗框），用线直线度（plumb-line）
  而不是仅靠 SIFT 特征点来拟合，精度会高一个量级。

## 5. 结论

1. 四张都成功解出镜头/焦距/失真开关，镜头确认为 **AF-S DX 18-70mm f/3.5-4.5G IF-ED**，
   DX 裁切模式；
2. 第 4 张 raw 被截断，只用于元数据/预览，未参与畸变测量；
3. 18mm On/Off 的 raw-vs-JPEG 对比给出约 1.5% 的径向差异，方向正确，但受限于角落
   无匹配点，**尚不能定量**；
4. 下一步建议：补拍 18mm 端带直线网格的 On/Off 两组，改用 plumb-line 拟合。
