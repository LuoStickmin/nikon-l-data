# Notice

This repository contains an independent, read-only structural analysis of the
Nikon "L" / distortion-control data format ("Distortion Control Data", shown as
`L` / `LD` in the camera firmware menu).

- No Nikon firmware, update package, or extracted data file is distributed
  here. Obtain them from Nikon's public download center and verify the SHA-256
  hashes listed in README section 1.
- The firmware images mentioned in the notes (D750 / D780 / D3300 modules) are
  not distributed either.
- The numeric tables under `out/` are the author's own analysis output (field
  dumps, recovered keystream values and decoded coefficients). They are shared
  for research and reproducibility only.
- "Nikon", "NIKKOR" and related marks belong to Nikon Corporation. This project
  is not affiliated with or endorsed by Nikon.
